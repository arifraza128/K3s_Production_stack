# ADR 005: AWS S3 (`ap-south-1`) vs Backblaze B2 for DR Backups

- **Status:** Accepted
- **Date:** 2026-11-08

## Context
Phase 8 requires off-node object storage for Velero cluster backups, Gitea `pg_dump` database archives, and Sealed Secrets master key backups.

## Decision
Use **AWS S3** in `ap-south-1` (Mumbai) co-located with our EC2 instance.

## Consequences
- **Pros:**
  - Zero data-transfer egress fees between EC2 (`ap-south-1`) and S3 (`ap-south-1`) during backups and DR restores.
  - Native IAM Instance Profile / IRSA authentication without static third-party API keys.
  - Native `velero-plugin-for-aws` EBS snapshot integration (`volumeSnapshotLocation`).
- **Cons:**
  - Slightly higher per-GB storage price (`$0.023/GB` vs `$0.006/GB` on Backblaze B2), which is negligible (`<$0.15/mo`) at our `< 5GB` backup footprint.
